途关 Waygate · 功能架构

v1.4.0

五域能力地图：控制台 · 接入 · 多提供商 · 数据口径 · 运行保障。条目均对应已实现的功能。

控制台

React 19 单页 · 7 页 · 明暗双主题（跟随系统）

  • 概览 —— 按客户端归属的用量摘要、积分实扣、渠道告警
  • 积分与用量 —— 趋势图（Token / 请求数双口径，等距时间轴补空桶）、按模型 / 客户端拆分、缓存命中率与缓存 token 计量
  • 提供商管理 —— 提供商行（额度、健康、签到）+ 密钥绑定与路由优先级
  • API Keys —— 权限范围（全部/按族/按模型/按标签）、IP 上限与白名单、token 配额
  • 请求日志 —— 逐条留痕（含 SSE）、游标分页、按密钥筛选、一键取证 30 分钟、留存清理
  • 设置 —— 8 组 30+ 项，含提供商凭据、限额、日志、签到与危险操作
  • 外观 —— 明暗双主题，跟随系统 / 手动切换（侧栏底部）

接入

双方言出口 · 一把密钥走所有客户端

  • OpenAI 兼容 —— /v1/chat/completions，流式 / 非流式
  • Anthropic 兼容 —— /v1/messages，Claude Code 等走 x-api-key
  • 密钥形态 —— sk-waygate-*（控制台创建，明文仅显示一次）
  • 协议翻译 —— OpenAI ↔ Anthropic 与三种上游方言互译

多提供商

三家可同时生效 · 按模型 id 路由

  • WorkBuddy —— openai 方言 · ck_ 静态密钥
  • MiniMax Code —— anthropic 方言 · OAuth 自动续期
  • Qoder CN —— COSY 协议 · 客户端登录态身份
  • 路由规则 —— 精确匹配（大小写敏感）→ 提供商内模糊回落；声明行优先于 observed

积分与领取

不做标定 · 上游说多少就是多少

  • 实扣口径 —— 积分 = 上游回报 usage.credit；未回报即 null（界面 —），绝不估算
  • 积分账本 —— MiniMax credit/details 真实余额（精确到 0.01）
  • 签到与领取 —— WorkBuddy 签到代领、成长任务、连登兑换（v1.4.0 OAuth 领取域）
  • 额度真值 —— 三家额度分别取其权威来源；取不到就明说
  • 不变式 —— ΣbyModel = ΣbyClient = creditsUsed，服务端断言后才返回

运行保障

自托管单机 · 反代保真

  • 并发闸 —— 槽位占用实时可观测（不泄漏、不单调上涨）
  • 断流重试 —— Qoder 零内容断流自动重试一次（客户端无感）
  • 渠道降级 —— 上游 11128 渠道校验自动降级重试
  • 留存与备份 —— 日志按天清理；SQLite VACUUM INTO 备份、冷热双份可回滚

图中每一条都对应已实现的代码路径，无规划项。版本 v1.4.0 · 与 server/src/version.ts 同源。
