控制台

React 19 单页 · 6 页 · 明暗双主题（跟随系统 / 手动切换）

  • 概览 —— 按提供商归属的用量摘要、积分实扣、渠道告警
  • 积分与用量 —— 趋势图（Token / 请求数双口径，等距时间轴补空桶）、按模型 / 提供商拆分、缓存命中率与缓存 token 计量
  • 提供商管理 —— 提供商行（额度、健康、签到、官方授权导入）+ 密钥绑定与路由优先级
  • API 密钥 —— 权限范围（全部 / 按族 / 按模型 / 按标签）、IP 上限与白名单、token 配额
  • 请求日志 —— 逐条留痕（含 SSE）、首字 / 耗时 / 输出速度、游标分页、按密钥筛选、一键取证 30 分钟、留存清理
  • 设置 —— 8 组 27 项，含提供商策略、限额、日志、签到与危险操作

接入

双方言出口 · 一把密钥走所有客户端

  • OpenAI 兼容 —— /v1/chat/completions，流式 / 非流式
  • Anthropic 兼容 —— /v1/messages，Claude Code 等走 x-api-key
  • 密钥形态 —— sk-waygate-*（控制台创建，明文仅显示一次）
  • 协议翻译 —— OpenAI ↔ Anthropic 与三种上游方言互译
  • 流式保活 —— 写头后以 SSE 注释 : ping 心跳，长思考不被网关判空闲

多提供商

多家可同时生效 · 按模型 id 路由 · 订阅走官方授权，OpenAI 兼容端点手填即接

  • WorkBuddy —— openai 方言 · 官方 OAuth 授权（v1.6.13 起 ck_ 已退役）
  • MiniMax Code —— anthropic 方言 · OAuth 自动续期
  • Qoder CN —— COSY 协议 · 客户端登录态身份
  • 自定义提供商（v1.10.0）—— 任意 OpenAI 兼容端点：Base URL + API Key 手填即接；URL 智能解析（带不带 /v1 都行，表单实时预览）；清单拉 /v1/models 或手动补；出站纯 Bearer 透传（无指纹 / 不改写 / 无重试梯）；单次积分如实 --（不标定）
  • 凭证导入 —— 选客户端 → 跳官方授权页 → 回来自动落盘；「未授权」信号三家各不相同（业务码 / authorization_pending / 404）；私有状态只存服务端
  • 路由规则 —— 精确匹配（大小写敏感）→ 提供商内模糊回落；声明行优先于 observed

积分与领取

不做标定 · 上游说多少就是多少

  • 实扣口径 —— 积分 = 上游回报 usage.credit；未回报即 null（界面 —），绝不估算
  • 积分账本 —— MiniMax credit/details 真实余额（精确到 0.01）；Qoder v2/me/usage 真实余额
  • 签到与领取 —— 三家代签（MiniMax 08:05 / Qoder 10:05 / WorkBuddy）；WorkBuddy 另有成长任务与连登兑换
  • 额度真值 —— 三家额度各取其权威来源；取不到就明说
  • 不变式 —— ΣbyModel = ΣbyProvider = creditsUsed，服务端断言后才返回

运行保障

自托管单机 · 反代保真

  • 并发闸 —— 槽位占用实时可观测（不泄漏、不单调上涨）
  • 断流重试 —— Qoder 零内容断流自动重试一次（客户端无感）
  • 渠道降级 —— 上游 11128 渠道校验自动降级重试
  • 渠道熔断 —— 连续 3 次「降级也 11128」即判渠道级故障：后续请求毫秒级快速失败、不占并发槽（否则阵发期每个失败烧 65s，把槽占满并饿死其他提供商）；冷却 30s 起指数退避封顶 300s，到期半开放行探测
  • 审计保行 —— 请求在途时密钥被删，落库撞外键即降级归属为 NULL、整行照常留存（note 标 key_deleted_inflight）
  • 留存与备份 —— 日志按天清理；SQLite VACUUM INTO 备份、冷热双份可回滚
